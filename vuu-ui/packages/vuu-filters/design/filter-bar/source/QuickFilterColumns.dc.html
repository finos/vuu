Choosing and ordering quick filters

The columns button at the end of the quick-filter bar opens a ColumnPicker variant. Checked columns are shown in the bar, in the order listed under Shown; drag the grip, or use Alt+↑/↓, to reorder. Unchecked columns are listed alphabetically under Available. Changes apply live and are reported through onChangeQuickFilterColumns, so the app can persist them. Reset restores the configured columns and order.

Configuration

FilterBar / QuickFilterProps
PropPurpose
variantExisting. "custom-filters-only", "quick-filters-only", or both; when both, the lead button toggles between them.
filterMode / defaultFilterModeExisting. Which mode is shown; onChangeFilterMode reports a toggle so the app can persist it.
quickFilterColumnsExisting. The columns shown and their order. Also what “Reset to default” restores, unless a separate default is supplied.
onChangeQuickFilterColumnsExisting. Called with the new list after a check, uncheck or reorder.
allowAddColumnExisting. Shows the columns button; when false, the configured set is fixed.
showFindExisting. true searches every string column; a list of names limits it to those. The control is labelled “Search”.
