Quick filter fields: shaded label, white input

Each quick filter is one outline split into two sections: the column name on a light grey fill and the input on white, so it’s clear exactly where to type. There’s no dropdown icon: the value list opens on click, ArrowDown or typing. A set filter shows a ✕ hard right in its input, with no separator.

LabelThe grey section holds the column name. It’s the field’s accessible name, and clicking it focuses the input. The edge between grey and white shows where typing starts, with no divider line. InputThe white section, 40px when empty and growing with its value up to 160px. Search is a plain white box. SetThe outline turns accent and the label section takes the accent tint; the input stays white. The ✕ sits hard right in the input, 2px from the outline. OperatorNumeric and date columns show their operator in the label section, as a small text button.
