Labels in a 28px bar

There’s no room for a label above each control, so every option keeps the column name on the same line as the value. A and D also keep the column name visible once a value is set.

Switching modes with the filter toggle button

The lead button is a toggle (aria-pressed). Clicking it switches between saved-filter pills and quick filters; hovering it still shows the summary overlay. The badge counts every applied clause in both modes. Applied saved filters stay applied while quick filters are shown, and the overlay lists them.
